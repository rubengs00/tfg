# Guia de Estilos

## Identidad visual

MusicHub usa una estetica oscura, compacta y orientada a biblioteca musical. La prioridad visual es que el usuario pueda escanear rapidamente canciones, albumes y acciones.

## Tipografia

- Fuente principal: Inter o system-ui.
- Titulares grandes solo en cabeceras de pantalla.
- Paneles, modales y tablas usan textos mas contenidos para favorecer lectura.
- Letter spacing neutro.

## Componentes

- Botones primarios verdes para acciones principales.
- Botones circulares con iconos para acciones repetitivas.
- Tarjetas solo para elementos repetidos: artistas, albumes, playlists.
- Modales para edicion de perfil, playlists y detalle de playlists.
- Barra inferior fija para el reproductor.

## Responsive

- Sidebar lateral en escritorio.
- Navegacion horizontal superior en tablet y movil.
- Grids adaptativos con dos columnas en movil cuando aporta densidad visual.
- Filas de canciones simplificadas en pantallas pequeñas.
- Reproductor reorganizado en dos filas en movil.
