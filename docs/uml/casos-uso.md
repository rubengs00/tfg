# Casos de Uso

## Usuario visitante

- Registrarse con nombre, email y password.
- Iniciar sesion.
- Completar verificacion de doble factor.
- Explorar catalogo publico.
- Buscar artistas, albumes y canciones.

## Usuario autenticado

- Editar perfil.
- Reproducir previews.
- Anadir y quitar canciones favoritas.
- Seguir y dejar de seguir artistas.
- Crear, editar y eliminar playlists.
- Anadir y quitar canciones de playlists.
- Consultar biblioteca personal.

## Administrador

- Acceder al panel privado de administracion.
- Consultar estadisticas reales del sistema.
- Ver usuarios y detalles de biblioteca.
- Crear, editar, activar, desactivar y eliminar usuarios.
- Activar o desactivar 2FA a usuarios.
- Eliminar playlists de usuarios.
- Revisar logs de actividad y errores de API.

## Sistema externo

- Spotify proporciona datos de catalogo.
- El servicio de correo envia codigos 2FA.
